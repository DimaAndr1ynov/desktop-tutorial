# Папка для фотографий

Загружайте сюда фото и видео-превью для сайта.

## Как загрузить

1. Откройте эту папку на GitHub
2. Нажмите **Add file → Upload files**
3. Перетащите картинки в окно
4. Внизу нажмите зелёную кнопку **Commit changes**

## Что дальше

После загрузки напишите Claude в чате, например:

- «привяжи фото из papki photos к портфолио»
- «поставь team.jpg в hero-карточку»

Claude сам подключит файлы к нужным местам сайта.

## Рекомендации

- Формат: JPG (для фото) или WebP
- Размер: до 1–2 МБ на файл (большие фото замедляют сайт)
- Понятные имена на латинице: `team.jpg`, `freeride-1.jpg`, `slalom-sunset.jpg`
